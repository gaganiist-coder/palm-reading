# Palm Reading · हस्तरेखा

A mobile web app that reads the **left palm**. It uses a live camera with a hand-outline guide and auto-capture. It measures hand shape and finger proportions on the device, asks a few guided questions about the lines, then gives a 10-area reading: personality, love, marriage, mind, vitality, career, wealth, success, leadership, intuition and travel.

- Rules are drawn from classic palmistry (Cheiro, *Language of the Hand*; Benham, *The Laws of Scientific Hand Reading*) and Hast Rekha Shastra.
- Photos never leave the phone. Hand tracking (MediaPipe Hand Landmarker) runs in the browser.
- Single static file (`index.html`), hosted on GitHub Pages.

For entertainment and self-reflection only. It makes no health or lifespan predictions.
